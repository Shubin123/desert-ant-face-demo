# Face web demo

[Open the site](https://shubin123.github.io/desert-ant-face-demo/)

Face matching across a photo library or through a video.

**Status: access/integration page, not functional inference.** The model weights are access-restricted. This page does not download private weights or simulate predictions. Authorized model access and a compatible inference runtime are needed to activate this demo.

Powered by [Desert Ant Labs](https://desertant.com) 🐜. See [ATTRIBUTION.md](ATTRIBUTION.md). Model ownership remains with Desert Ant Labs B.V.

## Run locally

Serve with python3 -m http.server 8080 --directory site and open http://localhost:8080. The included workflow publishes to GitHub Pages. The canonical SVG icon matches Shubin123/portfolio in both the favicon and site header.
